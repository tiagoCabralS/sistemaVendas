# projetoVendas

Projeto de exemplo para gerenciamento de vendas desenvolvido em Windows Forms (.NET 10).

Visão geral
- Aplicação desktop para controlar categorias, clientes, produtos e vendas.
- Interface construída com Windows Forms (WinForms) usando C#.

Principais funcionalidades
- Cadastro e edição de categorias, clientes e produtos.
- Registro de vendas com itens vinculados a produtos e clientes.
- Estrutura simples pensada para aprendizado e extensão.

Tecnologias
- .NET 10
- C#
- Windows Forms (WinForms)

Estrutura do repositório
- projetoVendas/: código-fonte do aplicativo WinForms
- .github/: workflows de CI
